# five.js

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

#### JavaScript multiplayer game server framework

Five.js aims to make it straightforward to build authoritative multiplayer game servers in JavaScript and TypeScript. It focuses on server simulation and state synchronization for web games, with Three.js as a target for client examples.

[Issues](https://github.com/Jecvay/five.js/issues) — [Releases](https://github.com/Jecvay/five.js/releases) — [Release guide](./RELEASING.md)

### Usage

Five.js is in early development. The public API and the first runnable example are pending.

### Cloning this repository

```sh
git clone --depth=1 https://github.com/Jecvay/five.js.git
```
